# Reproducibility package — Ensemble Dispersion of Adjoint Sensitivities (CASS)

Code and processed data for the IEEE Access manuscript
*"Ensemble Dispersion of Adjoint Sensitivities Under Atmospheric Initial-Condition Uncertainty for Quadrotor Diagnostics and Decisions"*.

Every number, table and figure in the manuscript is generated by the scripts
below from one pipeline. The manuscript never contains hand-typed results:
`scripts/s07_tables.py` writes them to `tables/numbers.tex` and the `tab_*.tex`
files, which the LaTeX source `\input`s from its `generated/` folder.

Repository: https://github.com/researchrepro6-lab/CASS-Reproducibility

```bash
git clone https://github.com/researchrepro6-lab/CASS-Reproducibility.git
cd CASS-Reproducibility
```
(or use *Code > Download ZIP* on the repository page and unpack it).

The manuscript source is not part of this package. To recompile the paper as
well, unpack its LaTeX source into `paper/` (so that `paper/main.tex` exists);
`run_all.py` then copies `figures/` and `tables/` into it and compiles it.

## How to reproduce

Requirements: Python 3.10-3.14 (64-bit) and the packages in `requirements.txt`.
LaTeX is optional: with LaTeX installed the figures are typeset exactly as in the
manuscript; without it they use matplotlib's built-in renderer (same content,
slightly different fonts).

### Windows with IDLE (no terminal needed)
1. Open `install_requirements.py` in IDLE and press **F5**. It installs the packages for
   the same Python that IDLE uses and then checks the setup (needs internet; once only).
2. Open `run_quick_test.py` and press **F5**: every script is tested in about 5-10 min
   (in a temporary copy; the shipped results are not changed).
3. Open `run_all.py` and press **F5** for the full run (about 1-1.5 h).

Any single script in `scripts/` can also be opened and run with F5 (`s03` and `s04`
take about 10 and 50 minutes). `extract_cass_subset.py` is not needed: it only rebuilds
`data/raw/cass_wind_subset.npz`, which is included, from the original archive file.

### Windows (Command Prompt or PowerShell)
```bat
cd "path\to\CASS-Reproducibility"
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python run_all.py --check
python run_all.py --quick
python run_all.py
```
(`py` is the Windows Python launcher; use `python` if `py` is not available.
In PowerShell, if activation is blocked, run
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` once, or skip the virtual
environment.) Alternatively, double-click `run_all.bat`.

### Linux / macOS
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_all.py --check
python run_all.py --quick
python run_all.py
```

### What the three commands do
* `--check` verifies Python, every package, float64 support in JAX, the Clarabel
  solver and the input data; it runs nothing.
* `--quick` runs all eight scripts with reduced sizes (about 5-10 min) in a
  temporary copy of the folder, so the shipped `results/`, `figures/` and `tables/`
  are not changed. Use it to confirm that everything runs on your machine.
* without options, the full pipeline (about 1.5-2 h on 2 CPU cores; `s03` and
  `s04` take most of the time) regenerates `results/`, `figures/` and `tables/`
  and then reports how many of the 275 manuscript numbers are identical to the
  shipped ones. `python run_all.py --from s06` restarts from a given step.

Individual scripts can also be run directly, e.g. `python scripts/s07_tables.py`;
each step reads the outputs of the previous ones from `results/` (shipped with the
package), so any single step can be rerun on its own.

Tested on Python 3.13 with NumPy 2.5.3, SciPy 1.18.1, JAX 0.12.0.1, CVXPY 1.9.3,
Clarabel 0.11.1, Matplotlib 3.11.2 (exact versions in `requirements-exact.txt`),
and on Python 3.10 with NumPy 1.26.4, SciPy 1.11.4, JAX 0.4.30, CVXPY 1.4.4,
Clarabel 0.7.1, Matplotlib 3.7.5, with and without LaTeX.

### Troubleshooting
* `No module named 'jax'` (or numpy, cvxpy, ...) - the packages are not installed for
  the Python that runs the script (IDLE, a terminal and a virtual environment can each
  use a different Python). Run `install_requirements.py` with that same Python (in IDLE:
  open it and press F5).
* `pip` cannot find a version - use Python 3.10-3.14 (64-bit); 32-bit Python, Python
  3.9 or older and Python 3.15 are not supported by JAX/CVXPY.
* `latex could not be found` or a LaTeX error in `s06` - not needed any more; the
  script detects LaTeX automatically. Set `CASS_NO_LATEX=1` to force the built-in renderer.
* A step seems to hang - `s03` and `s04` run for tens of minutes; progress is printed.

### Starting from the original archive file
`data/raw/cass_wind_subset.npz` was produced from `ECMWF_Aligned_July2022.nc`
(TIGGE, ECMWF ENS, 50 perturbed members, step 0, 00/12 UTC, July 2022,
0–30°N, 60–120°E) with

```bash
pip install xarray netCDF4
python scripts/extract_cass_subset.py path/to/ECMWF_Aligned_July2022.nc
```
which writes `data/raw/cass_wind_subset.npz` (an optional second argument sets another
output folder). This step is only needed to rebuild the input from the archive file;
the subset itself is included in the package.

The TIGGE data are available from https://ecds.ecmwf.int/datasets/tigge-forecasts.

## Numerical conventions
* Primary simulations and all derivatives: classical RK4, 2000 steps (Δt = 1 ms), float64
  (JAX). The continuous adjoint (DOP853, SciPy) is used only as an independent check.
* Gradients: reverse-mode AD through the integrator = exact discrete adjoint.
  Hessians and K = ∂g/∂w: forward-over-reverse AD.
* Characteristic scales S = diag(m g, I_B α_ref) with α_ref = 0.5 rad s⁻²
  = diag(14.715, 0.015, 0.015, 0.025).
* Scaled statistics: c = Sᵀ ḡ, H = Sᵀ D S (S diagonal, so Sᵀ = S).
* Covariances use the unbiased divisor E − 1.
* Bootstrap: E members drawn independently with replacement; eigenvector angles are
  sign-invariant (|v·v'|); scale rescaling multiplies each entry of S by its own
  log-uniform factor in [0.5, 2].
* Units: J in m² (tracking term), so the regularization weights γ_T, γ_τ are in m².
* Random seeds are fixed in every script.

## Key results (regenerated by the scripts)
* Gradients: Taylor order 2.000 for all verification members; continuous adjoint
  converges at second order in the quadrature nodes.
* 1,984 cases (62 times x 32 locations): the 4-D gradient dispersion is effectively
  rank 2 in every case; the quadratic-drag feature |w|w explains it (median relative
  error ~0.009), whereas the tangent K Sigma_w K^T holds only for small s/|w_bar|.
* Decision experiment (out of sample): the first-order dispersion penalty equals the
  mean-only rule below beta*, and curvature-aware rules (Mean-2, CASS-2, SAA, CVaR)
  perform best.
